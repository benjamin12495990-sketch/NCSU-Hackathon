# SURFPRO source data

> Reconstructed in this repository from the documentation snapshot of commit eff7c37 (branch experiment/physics-capped-age, another workspace, not pushed). The file was downloaded again here and its SHA-256 matches the value recorded in that snapshot.

`S129_SURFPRO.csv` is the unchanged CSV from the latest Zenodo record of the SURFPRO surfactant property database; `S129_SURFPRO_notes.txt` is the record's notes file.

- Record: Zenodo 15861809, version NORMAN-SLE-S129 0.1.1 (https://zenodo.org/records/15861809).
- Source paper: Hödl et al. (2025), DOI 10.1039/D4DD00393D.
- Record licence: CC BY 4.0; cite the dataset and the paper when redistributing or using derived results.
- CSV size: 799,214 bytes; Zenodo MD5 `e5bcd1bbab2fc56717a3cd6a0cf1c152` (matches); local SHA-256 `316a136630ab08097454518231b952c78d65773a125627ae38d874b889b8d841`.
- Contents: 1,624 surfactant structures, 1,395 pCMC measurements and 972 air-water surface tension measurements at the CMC. Measurement reference fields are retained for study-grouped splits.

The measured properties are precursors for a cleaning research programme. They are not cleaning-efficacy scores, and the CSV does not describe full detergent formulations or cleaning assays.
