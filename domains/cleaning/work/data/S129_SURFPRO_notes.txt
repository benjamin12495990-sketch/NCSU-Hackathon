Number : S129
Code : SURFPRO
Short Name : Surfactant Property (SURFPRO) Database

Short Description : Database of 1624 surfactants and properties from Hödl et al. 

Description : SURFPRO is a surfactant property database of 1624 surfactants and their physical properties, including 1395 experimental measurements of the critical micelle concentration (pCMC), 972 air-water surface tension at CMC, and Tmax, pC20 and further properties for over 657 surfactants curated from 223 literature sources. The SurfProf GitHub repository at https://github.com/BigChemistry-RobotLab/SurfPro contains all code. See Hödl et al. (2025) DOI:10.1039/D4DD00393D
