## 1. The expensive outcome

run, an assay)_

## 2. Dataset
- Source + citation (record in `../../research/references/<domain>.md`)
- Size, features, units, licence

## 3. Candidate space
How new candidates are generated by perturbing known-good examples; what constraints keep them
physical.

## 4. Models
- Expected-value model
- Cautious (lower-estimate) model and its target quantile
- Held-out split **by entity**, not by row, to avoid leakage
- Test metrics (MAE / RMSE, etc.)

## 5. Cost objective
What candidates are ranked by (CO2, price, toxicity, synthesis difficulty) and where every
non-learned number in it is sourced.

## 6. Lab-supported check
