# Reference entry template

Copy one block per sourced number into the matching `research/references/<domain>.md`.

```
### <what the number is> — <value> <unit>

- **Used in:** <file / model / page where this number appears>
- **Source:** <Author(s) (Year), Journal/Publisher>
- **Link:** <DOI or stable URL>
- **Retrieved via:** <OpenAlex / Scite / SciSpace / Wiley / PubMed / …>
- **Second check:** <independent search that confirmed it, or "not confirmed">
- **Caveats:** <region, basis, assumptions, anything that limits the number>
```

Keep caveats honest — e.g. "Australian concrete, includes transport", "seen only in a secondary
table", "assumption: not counted, no sourced factor found". The concrete factors in
`references/concrete.md` show the standard.
