Data-quality traps
Overlap: the Nguyen set re-publishes ICP, ISOCORRAG and MICAT first-year records. Adding the raw programme data as well would duplicate rows.

Units: atmospheric data is usually in µm of thickness loss, not mm/yr. The same programmes also report deposition in mg/m²·d.

Mixed methods: salt-spray, immersion and atmospheric exposure are different tests, and they should not be pooled as one rate.

Not a rate dataset: the Coelho "Machine learning for corrosion" Mendeley set (CC BY 4.0) is a table of literature on ML models. It holds no corrosion-rate measurements, so I excluded it.
