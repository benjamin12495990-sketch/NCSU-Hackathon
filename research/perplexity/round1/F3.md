The experimental_dataset.csv you couldn't place comes from a Zenodo deposit by Schrödinger. Beyond that, I found few new openly licensed measured-Tg records, and most of the rest was blocked by licence or access terms.

Source of experimental_dataset.csv
It is distributed with Bhati, Afzal, Chew, Browning and Halls, "Glass Transition Prediction of Binary Copolymers…" (Schrödinger, 2026). The Zenodo record is DOI 10.5281/zenodo.19242815 and the licence is Creative Commons Attribution 4.0 International. The record describes the file as "Experimental Tg dataset for homo- and copolymers used for training ML model" (64.1 kB). The paper (Polymers 18(14):1727) says it holds 666 points: 301 from Bicerano's handbook and 365 from Penzel et al. 1997. Of these, 315 are homopolymers and 351 are binary random copolymers.

I found no usable, openly licensed record for item 3 (copolymer and blend Tg) beyond the Penzel part of the Schrödinger file. I also found no downloadable Tg file for item 4. The rows above are what I could verify, not a complete survey.

Access terms (question 2)
PoLyInfo. The terms on the PoLyInfo home page are restrictive:

NIMS holds the copyright.

No reproduction, republication or distribution to third parties is permitted without NIMS's written permission.

Registration is required, and mass downloading and web scraping are prohibited.

Unpublished data are sold as datasets for a fee.

Based on that wording, redistributing PoLyInfo rows, or a derived table that reproduces them, needs NIMS permission. I did not find any statement about training a model on PoLyInfo and showing it on a public site. Ask NIMS in writing. One public benchmark repo (PolymerBenchmark2026) excludes its PoLyInfo set as "Restricted" in all formats.

GREA. I found no licence or terms page for the GREA data. PolyMetriX lists GREA as one of its sources, and the PolyMetriX Zenodo record is CC BY 4.0. That licence covers the curated compilation. It does not show that the upstream sources allow redistribution, so the GREA licence is not stated.

Polymer Genome and Khazana (question 4)
Polymer Genome is a prediction platform. It does not publish a downloadable experimental Tg file. A NIMS listing says its software licence is not explicitly stated and that some datasets may sit on Khazana. The Khazana page I fetched named no Tg dataset or licence. Experimental Tg downloadable: none found. Licence: not stated.

What I'd add first
Schrödinger deposit (10.5281/zenodo.19242815). It is the only openly licensed record I found with copolymer compositions, and it is CC BY 4.0. Use the 351 Penzel copolymer rows as a composition-dependence test set.

PolyMetriX (already found). Use it as the main homopolymer base, with the Bicerano overlap removed.

Penzel et al. 1997 and Bicerano 2002 as primary sources. Verify method and heating rate there, because the Zenodo page does not give them. I did not locate a data record for either.

Data-quality traps
Computed values mixed with measured ones. The Schrödinger record holds MD- and ML-predicted Tg next to the measured file. The GitHub compilation's method column allows simulation_MD, so filter on it.

Duplicates and re-publication. The GitHub dataset is mostly the PolyMetriX deposit. Bicerano-derived sets appear several times (four PolyMetriX sources trace to Bicerano ), so use group-aware splits.

Mixed units. The GitHub file allows C or K per row.

Mixed methods. Method and heating rate are not stated for the Schrödinger file. The GitHub file mixes DSC, DMA, TMA and dilatometry.

Narrow copolymer chemistry. The copolymer rows are almost all acrylate-type, and copolymer Tg spans about 250 K against 550 K for homopolymers.

Papers with no data record (excluded)
Penzel, Rieger and Schneider, Polymer 38:325 (1997): copolymer Tg data are in the paper only, and I found no data record.

Bicerano, Prediction of Polymer Properties (CRC Press, 2002): a book with no open data record found.
