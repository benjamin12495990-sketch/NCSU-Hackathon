What I would add first
Starrydata2 dielectric subset. It is the only real lab-measured, temperature- and frequency-resolved set I found, and it includes microwave ceramics. Before using it, locate the dielectric project file and read its licence.

The Riebesell DFPT set. It is a large, citable record with a DOI. Use it only as extra computed pretraining data, kept separate from measured labels.

Morita et al. It is a quick benchmark for comparing your pipeline with a published model. It mostly re-uses Materials Project data.

Data-quality traps
Duplicate IDs in Starrydata. Releases published from 2026-04-01 to 2026-09-08 contain duplicated sample_id values. The README says 10.4% were affected in the 2026-09-03 snapshot, because they point to different papers. Use a release from 2026-09-08 or later, or join on (SID, sample_id). Figshare monthly archives are only fixed from 2026-10-01.

Calculations excluded from Starrydata. The changelog says "calculation" data types were dropped as of 2024-07. Older snapshots may still mix computed and measured values.

Computed values presented as data. DieDatabase breakdown strengths come from a formula, and its permittivities are ML-predicted. Neither is measured.

Materials Project drift. Morita's data is a March 2020 Materials Project snapshot, so it may differ from the current database.

Mixed conditions. Measurements come from different frequencies, temperatures and specimens (single crystal, ceramic, or sintered pellet). Literature extractions rarely state the density or porosity.
